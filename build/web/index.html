ODCS-RFC-101Standards Track · Core InvariantNovember 2026

Zero Intent Loss (ZIL) & Single-Frame Authority

Specifies the sub-16ms cryptographic commitment requirement. User interactions must transition to immutable local authority within a single 60Hz display frame.

[ODCS-RFC-101: MANDATORY INVARIANT SPECIFICATION] 1. FRAME BUDGET INVARIANT: Let T_user be the timestamp of physical user interaction (touch/click/key). The client runtime MUST mint a cryptographic receipt R within: Δt = T_receipt - T_user < 16.66 ms (1 display refresh at 60 FPS) 2. RECEIPT MINTING FORMULA: R = { "intent_id": UUIDv7(monotonic_timestamp), "action": String, "payload": Canonical_RFC8785(Data), "actor": String, "receipt_hash": SHA256(canonical_payload + prev_block_hash) } 3. LOCAL NON-BLOCKING COMMITMENT: Network socket state MUST NOT gate receipt minting. Even under 100% WAN blackout, the receipt is immediately persisted into the local Write-Ahead Log (WAL).
